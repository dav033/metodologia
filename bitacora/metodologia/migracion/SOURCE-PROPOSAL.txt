## 1. Executive Summary & Architectural Vision

`metodologia` has outgrown the boundaries of a passive prompt skill. It is currently a complete, zero-dependency Python autonomous software engineering platform (`40+` modules in `skill/scripts/`) trapped inside a `skill/` directory structure. Keeping the orchestration engine, web server, state machine, and multi-provider process supervisor coupled inside a skill folder creates brittle path resolution in hooks, context bloat, and friction when scaling across heterogeneous agent CLIs.

This specification defines a **two-phase migration** to invert the architecture into a **Complete Multi-Agent Engineering Workspace**:

1. **Phase 1 (Core Platform Extraction, Composable Skill Suite, & 5-Account Pool):**
   - Extract `skill/scripts/*.py` into an installable Python CLI package (`bt` / `bitacora`) with a clean `AgentDriver` abstraction.
   - Decompose the monolithic `SKILL.md` into a **modular suite of composable skills** (distinguishing *always-on core router*, *model-invoked engineering disciplines*, and *user-invoked orchestrators*).
   - Vendor and natively integrate **`tt-a1i/archify`** (validated interactive HTML diagrams) into `<project>/artifacts/` and the local web UI (`127.0.0.1:8765`).
   - Adapt and embed the highest-leverage engineering primitives from **`mattpocock/skills`** (`codebase-design`, `improve-codebase-architecture`, `domain-modeling`, `tdd`, `diagnosing-bugs`, `retro`, `writing-for-agents`, `wait-what`) directly into the `metodologia` workflow, trace graph, and `bt learn` telemetry.
   - Operate natively across the **initial 5-subscription pool**: **2× Claude Code** (`claude-1`, `claude-2`), **2× OpenAI Codex** (`codex-1`, `codex-2`), and **1× Google Antigravity** (`agy-main`), with intra-repository `git worktree` parallelism and cold-start starvation fixes.
2. **Phase 2 (6th Subscription Expansion — Z.ai GLM Coding Plan Integration):**
   - Plug the 6th subscription (**Z.ai GLM Coding Plan Pro/Max** running `glm-5.3` and `glm-5.3-flash`) into the workspace via an isolated Anthropic-compatible driver (`zai`).
   - Activate UTC+8 off-peak credit arbitrage ($0.5\times$ load weight during Americas daytime/evening and all weekend), error `1113` 5-hour/weekly credit window handling, and 4-family cross-provider milestone auditing (`claude` ↔ `codex` ↔ `antigravity` ↔ `zai`).
