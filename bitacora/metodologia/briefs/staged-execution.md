- `scheduler-run --rebase` moves a run to the latest frozen revision keeping accepted work: a useful primitive.
- Schema 1.3.0 has subplans, composition gates, published subplan versions (`bt_scheduler_owner_composition.reconcile_subplans`), integration lines `refs/m3/line/<run>/<role>/<scope>`; `RUN.projection.json` carries `subplans` (D-131 verification gate in `bt_verification.py`, merge gate in `bt_review.merge`).
