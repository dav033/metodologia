01901 | 
01902 | <!-- YAML
01903 | added: v0.9.12

01909 | 
01910 | * `msecs` {number} **Default:** 0 (no timeout)
01911 | * `callback` {Function}
01912 | * Returns: {http.Server}
01913 | 
01914 | Sets the timeout value for sockets, and emits a `'timeout'` event on
01915 | the Server object, passing the socket as an argument, if a timeout
01916 | occurs.
01917 | 
01918 | If there is a `'timeout'` event listener on the Server object, then it
01919 | will be called with the timed-out socket as an argument.
01920 | 
01921 | By default, the Server does not timeout sockets. However, if a callback
01922 | is assigned to the Server's `'timeout'` event, timeouts must be handled
01923 | explicitly.

01926 | 
01927 | <!-- YAML
01928 | added: v16.10.0
01929 | -->
01930 | 
01931 | * Type: {number} Requests per socket. **Default:** 0 (no limit)
01932 | 
01933 | The maximum number of requests socket can handle
01934 | before closing keep alive connection.
01935 | 
01936 | A value of `0` will disable the limit.
01937 | 
01938 | When the limit is reached it will set the `Connection` header value to `close`,
01939 | but will not actually close the connection, subsequent requests sent
01940 | after the limit is reached will get `503 Service Unavailable` as a response.
