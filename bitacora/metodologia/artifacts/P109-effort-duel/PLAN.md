# Owner-authorized medium/high effort comparison

## Scope

Three new self-contained difficult dossiers, each sent to GPT-6.1 Sol medium/high (Codex-2) and Claude Sonnet 5.5 medium/high (Claude Work). Twelve calls; no automatic retries or fallback. This is a separate exploratory pilot, outside the formal REQ-024 benchmark. No product implementation or routing-policy change.

## Frozen conditions

- Identical input and output ceiling within each case: 12 findings, 1,800 whitespace words, single JSON object, 900s plus 30s CLI watchdog allowance.
- Fresh native session per cell, no tools requested; effective Claude IDs checked. Requested effort retained in exact command flags; collector does not independently attest internal reasoning effort or effective Codex model identity.
- Thirty-one expected independent roots frozen before calls (E1=11; E2=10; E3=10). Deterministic arithmetic and modeled lifecycle witness checks precede execution; these are not product tests.
- One call per effective account at a time, two lanes. Order alternates per case and between accounts (protocol.json). Input cache/context can still differ; three cases cannot completely counterbalance every order effect.
- Capture final answer, usage, latency and quota before/after each cell. Preserve failed quota reads and missing usage as unknown. Rounded account quota does not imply exact per-effort spend.

## Adjudication

After all responses, create shuffled grading views with route and effort hidden. Judge these before opening the key; model writing style may still reveal identity. Map every finding to frozen roots; accept grouped detection, count duplicate roots once. A root detected is distinct from a safe proposed fix. Check numerical witnesses and recommended corrections against the contract and verified protections. Record unsupported assertions, conditional concerns and supported extras separately; extras do not expand the denominator. Mark JSON/word-limit violations even when manual root scoring remains possible. No invented weighted intelligence score or statistical superiority claim.
