# A/B protocol
Two fresh default-role subagents, same inherited model/effort, same scenario prompt with only the designated skill path differing. Neutral A/B labels; variants revealed after answers. Baseline is the exact pre-integration snapshot, not an older Git HEAD.
Six conversational scenarios; no real commands/side effects or writes by participants. Participants read only their designated skill package and relevant references. Runtime event counters provide cumulative input, cached input, output, reasoning and total tokens. Uncached input = input minus cached input. Visible final-answer tokens, if tokenized separately, must be labeled an estimate rather than runtime billing.
Grade 18 predeclared binary criteria. Compare actual run consumption and output length independently of quality. One run per variant is exploratory, not statistical proof. No RTK binary compression occurs because RTK is unavailable and scenarios are simulated. No prices or monetary savings inferred.
