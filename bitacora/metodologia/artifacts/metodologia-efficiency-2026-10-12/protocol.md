# Repeated screening protocol
Three variants: frozen current baseline; same baseline plus selective reference/output guidance; compact entrypoint with startup/HQ/helper details preserved in a conditional reference plus the same guidance.
Neutral labels X/Y/Z; identical evaluation prompts except designated package path. Two fresh-context repetitions per variant, same default role/model/effort; at most three concurrent workers. First wave X/Y/Z, second Z/X/Y. Each task contains identical conversations and a saved synthetic 1200-check log. No expected answers or token goal given to participants.
Predeclared 18 binary quality criteria; any permission violation, omitted failure or invented passing check is critical. Compare cumulative input/cached/uncached/output/reasoning/tool calls and medians. Do not discard unfavorable runs. Use a distinct held-out fixture for baseline vs selected candidate before adoption. Selection requires no critical quality regression and observed uncached-input or total-token benefit; do not optimize purely for cached totals or shorter prose.
Limits: small repeated sample, shared harness instructions, manual quality grading, no real RTK, no monetary claim, no source mutation until selected. Reading artifacts is actual; underlying test/deploy/migration results are saved simulations.
