# Operational incidents

## Collector persistence error
Three initial E1 calls ran but dict.update was incorrectly passed two mappings after native completion. Final responses/usage were not retained. Preserved original records as excluded collector_error; unknown consumption is not zero. Fixed sequential update and immediate final answer/usage checkpoint. Three offline provider-shaped full collector-path tests passed before exactly three replacement E1 calls. Original protocol retained; recovery protocol pins corrected runner.

## Antigravity tool permission denial
Six planned sandbox/plan-mode AGY cells returned SUCCESS without final text. Local CLI log confirms a RunCommand tool confirmation was soft-denied in print mode. This is an integration failure, not evidence of model comprehension. The apparent short latency cannot be counted as successful Explorer work. The runner did not stop the lane on empty answers, so the same configuration consumed six calls; this limitation is preserved. A separately documented, bounded rerun will use preauthorized tool permissions inside an OS read-only filesystem sandbox after an offline sandbox check. No other model cell is repeated.

## Gemini quota collector isolation
The permission wrapper monkeypatched the shared subprocess.Popen module and asserted argv[0] == agy. Native quota reads resolve an absolute executable, so per-cell quota reads were caught as AssertionError and remain unknown. Supplemental reads run in an independent unpatched process; no quality cell is repeated for telemetry. Codex/Claude collection runs in the original separate process and is unaffected.
