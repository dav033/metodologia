## 2. Purpose and users

A signed-out visitor or signed-in person answers: which tools does each plan include, and what is its monthly price in this interface language? Success is reading the four plans in catalogue order, recognizing unavailable tools, and returning to the originating surface. Custom-role users see the same comparison; staff permissions do not change its contents.

This is an informative working surface within Pictures. Users can fold/reopen lists and navigate within the comparison. They cannot buy, pay, subscribe, request, contact someone about a plan, register, change a plan or change access here. An administrator assigns plans on the existing accounts surface. No current-plan badge, selected-access tier, numerical limit, usage counter or limit-enforcement UI is added.

## 6. Flows

1. **F1 — Public comparison (V3 → V1).** Open `/login` → follow its sole Plans link → see four expanded bands without account menu → read/fold/reopen any list → follow Back to sign in → return to the unchanged sign-in context. Authentication is not required to compare.
2. **F2 — Signed-in comparison (V4 → V2).** Open the account disclosure from an authenticated page → follow its sole Plans link → see the same four plans with the existing account disclosure → read them → return to the recorded origin. The fixture starts and ends at Mi cuenta; production must support other same-origin entry pages too.
3. **F3 — Language (V1–V4).** English browser initially shows Enthusiast/Free and 7/14/25 USD per month. Spanish/unsupported browser shows Entusiasta/Gratis and 20.000/45.000/70.000 COP per month. Changing the local ES/EN control updates the visible comparison atomically; only one currency is visible.
4. **F4 — Fold and navigate (V1–V2).** All bands start expanded → activate Hide tools on any band → name and price remain → activate Show tools to restore that list, or use the band's local index link to expand and focus it. Other bands retain their presentation state. No catalogue values or account rights change.
5. **F5 — Catalogue recovery (V1–V2).** Missing/incomplete/unreadable catalogue → no guessed or partial price comparison → visible explanation and Retry → retry the same read → complete four-plan comparison or retained error. Fixture Retry restores ready immediately. If production catalogue is statically validated, build/load validation rejects invalid data upstream; no unnecessary client fetch or synthetic loading delay is prescribed.

### Verified behavioral correction and reproducibility

The direct rebuild reproduced a narrow defect when switching to Quieto **during** an expressive entrance: CSS band registration stopped, but Motion replaced tool-list WAAPI effects after the runtime's two-frame settling window, leaving roughly 300ms of list travel. Initial reduced-motion loads already passed. A focused browser reproduction observed those remaining running `.tool-list` effects; this is a real transition defect, not a failing contrast audit.

The canonical build corrects only that defect: key the `motion.ul` subtree by reduced state, so switching motion mode cancels the in-flight list animation and mounts the settled reduced list. The App and disclosure state are preserved. The exact source transform is:

```tsx
// Selected source marker:
<motion.ul className="tool-list" initial=
// Canonical in-memory replacement:
<motion.ul className="tool-list" key={profile.reduced ? "still" : "motion"} initial=
```

Reproduction uses the current `real/build.mjs` in memory: replace its single `b = await bundle("", "", "", abs);` call with `bundle(transformedSource, path.dirname(abs), abs)`, retaining all other builder code, aliases, CSS/font processing and offline dependencies; set its module location to the installed builder path. The transformed TSX exists only in memory and writes only `planes@v1.html`. No generated/minified HTML is hand-patched, no exploration/shared builder/runtime is edited and no additional source file is created. The selected source SHA above remains unchanged. All CSS and the expressive choreography remain unchanged. A focused final check observed four expressive band animations, then zero running animations 70ms after Quieto, with an already folded band still folded.
