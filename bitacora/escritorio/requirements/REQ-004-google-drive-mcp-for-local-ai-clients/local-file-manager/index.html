Integración personal · Protocolo MCP

Gestor local de archivos

Conecta clientes MCP instalados en el computador con la cuenta personal de Google Drive de su propietario para buscar, leer, crear, editar, compartir y organizar archivos.

Cómo funciona

El servidor MCP funciona localmente y escucha solo en 127.0.0.1. Codex, Gemini CLI, Claude Code y otros clientes locales pueden conectarse a ese servicio. Esta página pública es informativa: no aloja el servidor MCP ni recibe archivos de Drive.

La autorización de Google permite leer y modificar los archivos de Drive. La herramienta de eliminación mueve archivos a la papelera recuperable; no ofrece borrado permanente.

Datos y privacidad

Los datos se usan para ejecutar las operaciones que solicita el propietario. Los resultados se devuelven al cliente MCP local elegido por él; ese cliente puede procesarlos según las condiciones de su proveedor.

English summary

Local File Manager

A single-user local MCP server that lets installed AI clients work with the owner's Google Drive. It can search, read, create, edit, share, and move files to recoverable trash. The public website only provides information; it does not host the MCP server or receive Drive files.
