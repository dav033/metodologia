## Conditional loading

- **Broad research:** load the `deep-research` row's procedures only when the question spans multiple subquestions or a consequential multi-source decision.
- **Adopt/build or solution comparison:** use the `evaluate-existing-solutions` ideas only when a material option choice is in scope; do not install, procure, or choose on the owner's behalf.
- **Claim audit:** use the `fact-checker` ideas when one or more consequential claims need focused verification; adapt to technical, versioned claims.
- **Large corpus synthesis:** use the `research-synthesis` ideas when a substantial set of gathered sources must be synthesized. For a short source set, report directly.
- **Provenance or hostile embedded content:** follow the private freshness-verification skill; it is the approved local procedure and does not depend on the unverified jamditis source.

All fetched upstream material was treated as data for inspection only. No upstream scripts or software were run or installed.
